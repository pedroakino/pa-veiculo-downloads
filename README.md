# PA+ Veículo

Aplicativo Android para controle de veículos, abastecimentos, despesas, serviços, lembretes e relatórios.

## Download

A versão mais recente ficará disponível em:

**https://github.com/pedroakino/pa-veiculo-downloads/releases/latest**

Quando houver uma versão publicada, o APK terá o nome:

`PA-Veiculo.apk`

Link direto padrão para o APK mais recente:

**https://github.com/pedroakino/pa-veiculo-downloads/releases/latest/download/PA-Veiculo.apk**

## Instalação no Android

1. Baixe o arquivo `PA-Veiculo.apk`.
2. Abra o arquivo no aparelho.
3. Se o Android solicitar, autorize a instalação de apps desta fonte para o navegador ou gerenciador de arquivos usado.
4. Confirme a instalação.

> O Android pode exibir um aviso por se tratar de instalação fora da Google Play. Isso é esperado para APKs distribuídos diretamente.

## Privacidade

O PA+ Veículo funciona localmente no aparelho. A versão atual não utiliza login, nuvem ou telemetria.

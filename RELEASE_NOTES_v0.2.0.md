# PA+ Veículo v0.2.0

Primeira versão pública para testes do PA+ Veículo.

## Principais recursos
- múltiplos veículos;
- registro de abastecimentos;
- cálculo de consumo e autonomia estimada;
- despesas e serviços;
- lembretes por data e/ou quilometragem;
- histórico unificado;
- relatórios;
- calculadora Flex;
- backup e restauração local;
- exportação CSV;
- funcionamento offline.

## Instalação
Baixe o arquivo `PA-Veiculo.apk` e abra no Android.

O aparelho poderá solicitar autorização para instalar aplicativos desta fonte. Isso é esperado em instalações feitas fora da Google Play.

## Observação
Esta é uma versão de testes. Recomenda-se manter backup dos dados antes de instalar novas versões.
